# Topic: FDE Consulting Craft — The Consultant Half of Forward Deployed Engineering

## Why I Want to Learn This
Track 5 of the FDE (Forward Deployed Engineer) path, finance-vertical profile. The other tracks (prototyping, production AI systems, trading-domain fluency) prove I can build the thing. FDE roles are graded on a different axis too: can I sit in front of a skeptical client, turn a vague complaint into a scoped plan, run a live demo when something breaks, and write the follow-up document that gets a deal moving. Engineers underestimate this half and FDE interview loops — Palantir's Forward Deployed rounds especially — filter hard on it. This track exists so the consulting half isn't the reason I don't get the offer.

## Current Knowledge Level
none (as a trained skill) — I've sat in plenty of client meetings from the vendor and buyer side in trading, but I've never been drilled on discovery frameworks, timed case-study decomposition, or demo narrative structure. Strong technical credibility; the gap is entirely in the structured "read the room, scope the ambiguity, present with authority" mechanics.

## Goal
Be able to:
1. Run a discovery conversation with a skeptical financial-services stakeholder that surfaces the real problem, disqualifies bad AI-project candidates, and frames ROI in terms the stakeholder's boss will accept
2. Take a vague, one-sentence customer prompt and produce a scoped, defensible plan in 45 minutes under timer pressure — the signature FDE interview drill — and self-grade it against a rubric
3. Deliver a live product demo with a problem → stakes → resolution narrative, recover cleanly when the demo breaks, and handle a hostile or skeptical question without losing the room
4. Write a one-page solution brief and a lightweight SOW that a client's procurement and technical leads would both find credible
5. Run a full mock engagement end to end — discovery call, scoped plan, demo, follow-up brief — as a single dry run that simulates the actual interview loop or first client engagement

## Capstone: what artefact proves mastery?
This is a performance-skill course — recall quizzes prove nothing here. Every phase capstone is a graded performance artefact (recording, written document, or timed drill output), not a quiz score. Per-phase artefacts under `artefacts/fde-consulting-craft/phase-N/`:

- **Phase 1** — `artefacts/fde-consulting-craft/phase-1/discovery-scoping-brief.md` — a written discovery + scoping brief for a fictional financial-services client (a bank research desk or fund ops team), including stakeholder map, disqualified use cases with reasoning, and an ROI framing a non-technical sponsor would sign off on
- **Phase 2** — `artefacts/fde-consulting-craft/phase-2/` — three timed 45-minute case-study drill outputs (`drill-1.md`, `drill-2.md`, `drill-3.md`) of escalating difficulty, each a scoped plan produced from a vague prompt, each self-reviewed against a written rubric
- **Phase 3** — `artefacts/fde-consulting-craft/phase-3/` — recorded demo takes (`demo-take-1.mp4`/link + `demo-take-2-hostile-qa.mp4`/link) showing narrative structure, live-demo discipline, a recovered failure, and a handled hostile question
- **Phase 4 (course capstone)** — `artefacts/fde-consulting-craft/phase-4/` — a one-page solution brief, an SOW-lite, and a full mock-engagement recording (`mock-engagement.md` + recording link) covering discovery call → scoped plan → 10-minute demo → follow-up brief end to end
- **Course capstone (overall)** — a recorded 10-minute demo video, a one-page solution brief for a fictional financial-services client, a discovery-call script, and the end-to-end mock engagement dry run, together forming the portfolio artefact for FDE interview prep
